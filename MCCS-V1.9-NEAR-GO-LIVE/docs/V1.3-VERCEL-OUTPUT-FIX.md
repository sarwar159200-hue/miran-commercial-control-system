# MCCS V1.3 — Vercel Output Directory Fix

The Vercel deployment error was:

`No Output Directory named "public" found after the Build completed.`

For a Next.js application, Vercel should manage the `.next` build output automatically.
The project must NOT have `public` configured as its Output Directory.

## Required Vercel setting

Go to:

Project → Settings → Build and Deployment

Use:

- Framework Preset: **Next.js**
- Root Directory: **MCCS-V1.3-VERCEL-FIXED** (if you upload this package under that folder name)
- Build Command: leave as default / blank
- Output Directory: **leave blank**
- Install Command: leave as default / blank

If "Output Directory" currently says `public`, remove it completely and save.

Then redeploy without cache.

## Included fix

This package also includes:

`vercel.json`

with:

```json
{
  "framework": "nextjs"
}
```

No custom output directory is declared.
