## Login troubleshooting
MCCS uses Supabase `signInWithPassword()`. A password only works if the exact email exists as a user in the same Supabase project.

Check:
- Supabase project: `https://pzxslfhezmubslqqirao.supabase.co`
- Authentication → Users
- Exact user email: `sarwar.khalid@miranenergy.com`

If the user is missing, create it in Authentication → Users and set the intended password.
If the user exists but is unconfirmed, confirm it.
If the password is uncertain, reset it or use Forgot Password.
