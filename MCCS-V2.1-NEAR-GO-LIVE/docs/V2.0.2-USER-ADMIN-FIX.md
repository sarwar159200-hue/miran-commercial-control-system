# MCCS V2.0.2 — User Administration Fix

This version fixes the User & Roles screen so the service-role warning is no longer hard-coded.

The page now:
- detects `SUPABASE_SERVICE_ROLE_KEY` on the Vercel server
- shows a green "Server admin credential detected" status when available
- disables account creation only when the credential or roles are unavailable
- shows the actual Supabase role query error
- shows a clear warning when no roles exist
- adds `/api/admin/diagnostics` for Super Admin diagnostics without exposing any secret values

## IMPORTANT

After adding or changing a Vercel Environment Variable, you must create a NEW deployment / Redeploy.
An already-running deployment does not gain a newly-added variable automatically.

Also ensure the variable is applied to the same environment as the deployment:
- Production deployment -> variable must include Production
- Preview deployment -> variable must include Preview
