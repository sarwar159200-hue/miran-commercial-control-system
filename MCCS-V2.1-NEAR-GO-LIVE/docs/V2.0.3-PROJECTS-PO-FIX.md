# MCCS V2.0.3 — Projects + PO Detail Fix

## What this fixes

### 1. Projects missing from Administration
Administration now includes a Projects card.

Path:
Administration → Projects

You can:
- Add Project
- View projects
- Deactivate projects

Active projects populate the Project dropdown on New Purchase Order.

### 2. PO says "PO not found" after creation
The PO detail page no longer depends on one large embedded Supabase relationship query.
It now:
- reads the PO first
- reads Vendor separately
- reads Currency separately
- reads Project separately
- reads Revisions separately
- reads Milestones separately
- shows the real Supabase error if the PO itself cannot be read

PO creation also verifies the record can be read before redirecting to the detail page.

## SQL
Run:
`006_projects_and_po_detail_fix.sql`

after:
`005_fix_data_api_grants.sql`
