## One Vercel variable is still mandatory

The Supabase publishable/anon key is needed to authenticate users.

In Vercel → Project → Environment Variables, add either:

`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

or

`NEXT_PUBLIC_SUPABASE_ANON_KEY`

Apply to:
- Production
- Preview
- Development

Then redeploy.

The project URL can still be set explicitly as:

`NEXT_PUBLIC_SUPABASE_URL=https://pzxslfhezmubslqqirao.supabase.co`

but V1.6 also knows this public URL as a fallback.
