# MCCS V1.5 — Supabase / Vercel Prerender Fix

## Error fixed

Vercel failed while generating `/admin/onedrive` because the authenticated dashboard layout attempted to create a Supabase server client during the production prerender phase and threw when environment variables were not available.

V1.5 fixes this by:

- marking authenticated dashboard routes as `force-dynamic`
- disabling static revalidation for authenticated pages
- preventing the server Supabase helper from throwing during Vercel build
- redirecting to `/login?config=missing` if authentication variables are actually absent at runtime
- marking `/admin/onedrive` dynamic
- preserving the secure Supabase login workflow

## Vercel environment variables

In **Vercel → Project → Environment Variables**, confirm these exact variables exist:

`NEXT_PUBLIC_SUPABASE_URL`
Value example:
`https://pzxslfhezmubslqqirao.supabase.co`

and ONE of:

`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

or the older:

`NEXT_PUBLIC_SUPABASE_ANON_KEY`

Apply them to **Production** and preferably **Preview** + **Development**.

After adding/changing environment variables, create a NEW deployment / Redeploy. Existing deployments do not automatically inherit later environment-variable changes.
