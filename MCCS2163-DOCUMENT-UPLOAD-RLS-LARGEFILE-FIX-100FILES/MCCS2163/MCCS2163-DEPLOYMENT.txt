MCCS 2.16.3 - Document Upload RLS + Large File Reliability

- Fixes: Google Drive file succeeds but documents metadata insert is blocked by RLS.
- The completion API still authenticates the signed-in MCCS user first, then uses the
  server-only Supabase service role for the metadata insert.
- No new database migration is required for this fix.
- MCCS does not impose a total document file-size cap. Files use Google Drive resumable
  upload in 3 MB chunks with transient-error retries and a 2-hour signed upload token.
- Actual limits can still come from Google Drive storage/quota, browser/device memory,
  network availability, and hosting/runtime limits.
- Previous MCCS upgrades are preserved.
