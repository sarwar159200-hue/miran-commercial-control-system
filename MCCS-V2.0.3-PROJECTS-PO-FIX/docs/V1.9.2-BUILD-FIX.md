# MCCS V1.9.2 — Vercel Strict TypeScript Fix

This patch fixes the reported Vercel error:

`'pos' is possibly 'null'`

Supabase query `.data` values are typed as nullable. V1.9.2 explicitly normalizes them with:

```ts
const pos = poResult.data ?? [];
```

The same proactive normalization was also applied to:
- Vendors register
- Add Vendor form lookup arrays
- Add Purchase Order form lookup arrays
- Existing Super Admin Control Center arrays from V1.9.1
