# MCCS V1.9.1 — Vercel TypeScript Build Fix

This patch fixes the Vercel TypeScript error:

`'online' is possibly 'null'`

Supabase query result data is typed as `T[] | null`, so V1.9.1 explicitly normalizes query results:

```ts
const online = onlineResult.data ?? [];
const logs = logsResult.data ?? [];
```

This also normalizes the audit-log actor lookup.
