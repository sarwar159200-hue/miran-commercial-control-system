# MCCS V2.4 Deployment

1. Run `011_microsoft_storage.sql`.
2. Upload this folder to GitHub.
3. Vercel Root Directory: `MCCS-V2.4.0-MICROSOFT-STORAGE`.
4. Output Directory: blank.
5. Add Microsoft server environment variables.
6. Redeploy.
7. Administration → Microsoft Storage → Test Connection.
8. Initialize MCCS folders.
9. Documents → Upload File.
