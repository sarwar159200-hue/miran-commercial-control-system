# MCCS V1.4 — Login, Password Recovery & OneDrive Setup

## 1. Supabase login account

The MCCS login screen is prefilled with:

`prjoect.invoices@miranenergy.com`

The password is intentionally **not stored in GitHub source code**.

In Supabase:

1. Open **Authentication → Users**.
2. Choose **Add user / Create new user**.
3. Use the MCCS project-invoice email address.
4. Set the password you want for that account.
5. Confirm/create the user.

This makes the credential a real Supabase Auth account instead of a password exposed in the website code.

## 2. Supabase Auth redirect URLs

In Supabase **Authentication → URL Configuration**, configure your Vercel production URL as the Site URL.

Add redirect URLs for:

- `https://YOUR-VERCEL-DOMAIN.vercel.app/update-password`
- your future production domain, for example `https://commercial.miranenergy.com/update-password`

The Forgot Password screen uses Supabase `resetPasswordForEmail`, then the recovery page uses `updateUser` to set the new password.

## 3. Vercel Supabase variables

Keep:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

The existing older `NEXT_PUBLIC_SUPABASE_ANON_KEY` is also supported by the MCCS helper.

## 4. OneDrive configuration

MCCS is prepared for Microsoft Graph / OneDrive. You still need Microsoft 365 / Entra values from your company tenant.

Create/register an application in Microsoft Entra ID and obtain:

- Tenant ID
- Client ID
- Client Secret or preferably a stronger production credential
- OneDrive / SharePoint Drive ID that will hold MCCS documents

Then add these in **Vercel → Environment Variables** as server-only variables:

- `MICROSOFT_TENANT_ID`
- `MICROSOFT_CLIENT_ID`
- `MICROSOFT_CLIENT_SECRET`
- `ONEDRIVE_DRIVE_ID`
- `ONEDRIVE_ROOT_FOLDER` = `MCCS`

Do **not** prefix Microsoft secrets with `NEXT_PUBLIC_`.

The current code includes:
- OneDrive configuration status page: `/admin/onedrive`
- Server-side Microsoft token helper
- Server-side helper for small-file uploads to a configured Drive
- OneDrive status endpoint: `/api/onedrive/status`

Your Microsoft 365 administrator must approve the Graph permissions appropriate for the chosen storage model before live uploads are enabled.
