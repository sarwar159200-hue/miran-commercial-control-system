# MCCS V2.0 — GO-LIVE CONTROLS

## Fixed / Added
1. Vendor creation no longer throws a raw server-side application error; forms return visible errors.
2. Main Vendor and Sub-Vendor are now separate creation pages.
3. Currency Master is functional.
4. Super Admin Team Account creation is functional when `SUPABASE_SERVICE_ROLE_KEY` is configured server-side.
5. Purchase Orders now support:
   - detail page
   - amendment / revision history
   - hold / release
   - audit-preserving soft delete
6. Payment milestones can be added during initial PO creation.
7. Payment Milestone register is live.
8. Dashboard Export now downloads an Excel workbook with:
   - Purchase Orders
   - Vendors
   - Payment Milestones

## REQUIRED SUPABASE SQL
Run, in order, if not already run:
- `001_foundation.sql`
- `002_near_go_live.sql`
- `003_go_live_controls.sql`

The V2.0 features WILL NOT work correctly until `003_go_live_controls.sql` is run.

## REQUIRED VERCEL VARIABLES
Existing:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`

For Super Admin team-account creation add:
- `SUPABASE_SERVICE_ROLE_KEY`

Use the Supabase legacy/service-role key or server secret appropriate for Admin API use.
This is SERVER ONLY.
Never name it `NEXT_PUBLIC_...`.
Never commit it to GitHub.
