MCCS 2.17.9 - PO Milestone / Invoice Workflow / Permanent PO Purge / Speed

1. PO milestone saving
- New milestones entered while editing a PO are now persisted with the authenticated Super Admin action using the server service-role database client after permission validation.
- Existing milestones update in parallel and new milestones insert in one batch.
- The edit page reopens after save and shows a success message, making the saved milestones immediately visible.

2. Invoice status/workflow synchronization
- Super Admin invoice status edits now synchronize workflow_status.
- Approved remains compatible with the existing controlled workflow as approved_for_payment, while the register displays Approved.
- Paid status is now available and displays Paid in Workflow.
- Received, Under Verification, Submitted to AP and On Hold are reflected immediately.

3. Permanent deleted PO purge
- Super Admin can permanently purge a soft-deleted PO and its linked MCCS commercial database records.
- Child records are removed in foreign-key-safe order.
- One minimal purge audit event is retained.
- Google Drive physical files are not deleted by this database purge.

4. Performance
- Milestone saves no longer perform sequential insert/update round trips for every row.
- Existing milestone updates run concurrently; new rows use a single batch insert.
- No new page-load queries, polling, dependencies, or background processes were added.

All previous MCCS 2.17.8 upgrades are preserved.
