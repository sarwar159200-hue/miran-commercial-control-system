# MCCS V2.3.0 — Invoice Assurance & Approval Workflow

## New workflow
Received → Assigned → Under Verification → Technical Approved → Approved for Payment → Released to AP Queue.

Reviewer can approve or return with comments. Super Admin performs final commercial acceptance. All actions are logged in `invoice_approvals`.

## Verification Sheet
Each invoice has a printable verification sheet with PO/vendor/milestone data, cumulative certified and remaining commitment, approval history, Excel download, and Print / Save PDF.

## Database
Run `supabase/migrations/009_invoice_assurance_workflow.sql` after 008.
